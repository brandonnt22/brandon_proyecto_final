# Simulador Web de Abastecimiento, Precios y Consumo Familiar

## Descripción del Proyecto

Este proyecto fue desarrollado como parte del Desafío Final de Programación Web I. Su objetivo es aplicar los conocimientos adquiridos en HTML5, CSS3 y JavaScript para resolver problemas relacionados con situaciones reales que afectan a las familias y comunidades.

La aplicación permite simular diferentes escenarios económicos y sociales mediante formularios interactivos y cálculos realizados dinámicamente con JavaScript.

---

# Objetivos

## Objetivo General

Desarrollar una aplicación web interactiva que permita analizar situaciones relacionadas con transporte, compras familiares y abastecimiento de productos mediante simulaciones matemáticas.

## Objetivos Específicos

* Aplicar HTML5 para estructurar una página web semántica.
* Utilizar CSS externo para diseñar una interfaz moderna y responsiva.
* Implementar JavaScript para realizar cálculos dinámicos.
* Manipular el DOM para capturar datos y mostrar resultados.
* Validar información ingresada por el usuario.
* Presentar resultados claros e interpretables.

---

# Casos de Estudio Implementados

## Caso C: Simulador de Costo de Transporte

### Problema

Cuando existen bloqueos, rutas alternas o problemas en las carreteras, los transportistas deben recorrer mayores distancias, incrementando los costos de operación.

### Datos Solicitados

* Distancia normal (km)
* Distancia con desvío (km)
* Costo por kilómetro (Bs)
* Viajes por semana

### Resultados

* Costo normal
* Costo con desvío
* Diferencia de costos
* Costo adicional semanal
* Costo adicional mensual

---

## Caso D: Simulador de Compras Familiares

### Problema

Las familias administran un presupuesto limitado y necesitan evaluar si sus compras se ajustan a sus posibilidades económicas.

### Datos Solicitados

* Presupuesto familiar
* Nombre del producto
* Precio unitario
* Cantidad

### Resultados

* Total de compra
* Saldo restante
* Monto faltante
* Clasificación del gasto

---

## Caso E: Simulador de Rumor de Escasez

### Problema

Los rumores de escasez pueden provocar compras excesivas, aumentando artificialmente la demanda de productos.

### Datos Solicitados

* Demanda normal
* Porcentaje de aumento
* Stock disponible
* Número de familias

### Resultados

* Nueva demanda
* Demanda total
* Stock restante
* Estado de abastecimiento
